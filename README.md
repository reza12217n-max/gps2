# نقشه زمین

۱. همه‌ی فایل‌ها (با پوشه‌ی .github و resources) رو توی یک مخزن گیت‌هاب آپلود کن.
۲. بالای صفحه برو به Actions ← Build APK ← Run workflow.
۳. وقتی تموم شد، پایین صفحه‌ی همون اجرا، فایل zamin-naghshe-apk رو دانلود کن (app-debug.apk).
۴. APK رو روی گوشی نصب کن.

فونت وزیر موقع ساخت خودکار اضافه می‌شه. اگه نشد، فایل Vazirmatn.woff2 رو بذار توی www/fonts.
